# リスナビ 着信自動応答

lisnavi.com にログインしている間、着信があったら「応答」ボタンを自動でクリックする Tampermonkey ユーザースクリプト。

## インストール方法

1. Chrome/Edge に [Tampermonkey](https://www.tampermonkey.net/) 拡張機能を入れる
2. Tampermonkey のダッシュボード →「新規スクリプトを作成」
3. `lisnavi-auto-answer.user.js` の中身を全部貼り付けて保存
4. lisnavi.com のページを開く(もしくはリロードする)

有効/無効は Tampermonkey のアイコンを右クリック(またはメニュー)から「自動応答のON/OFFを切り替え」で切り替えられる。デフォルトは有効。

## 現状の検知ロジック(暫定版)

実際の「着信中」画面のDOM構造がまだ分かっていないため、暫定的に以下の2通りで検知している。

1. **着信音の再生検知**: ページ内で `<audio>` の再生(`play()`)が呼ばれたら着信とみなす
2. **DOM監視**: 画面に新しい要素が追加されるたびに、テキストが「応答」「出る」「応答する」「通話開始」のいずれかに一致する、クリック可能なボタンを探す

どちらかで着信を検知したら、見つかった応答ボタンを自動クリックする。誤動作防止のため、クリック後3秒間は再クリックしない。

## 精度を上げるためにやってほしいこと

このロジックは推測ベースなので、実際の着信で期待通り動くか確認してほしい。

- **動いた場合**: そのままでOK。ただし「関係ないボタンを誤クリックしていないか」だけ念のため確認してください。
- **動かなかった場合**: 実際に電話が鳴っている瞬間に Chrome の DevTools を開き(F12)、

  1. Elements パネルで着信中に表示される要素(応答ボタンや着信中インジケータ)を探す
  2. その要素を右クリック →「Copy → Copy outerHTML」
  3. コピーした内容を共有してください

  これをもとに `lisnavi-auto-answer.user.js` 内の `ANSWER_BUTTON_TEXT_PATTERNS` や検知ロジックを、実際のクラス名・構造に合わせて確定版に書き換えます。

## 注意点

- 離席中でも自動応答してしまうため、実際の業務フローに合っているか(例えば「離席」ボタンを押していれば着信自体が来ない設計かどうか)を確認した上で使うこと
- リスナビ側の画面更新(UIアップデート)でセレクタが変わると動かなくなる可能性がある
